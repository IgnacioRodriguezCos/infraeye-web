CORRECCIONES ISO 690:2010 - REFERENCIAS BIBLIOGRÁFICAS
========================================================

Se identifican tres tipos de errores recurrentes en biblio.bib:

==============================================================
ERROR 1: AUTORES CORPORATIVOS ABREVIADOS
==============================================================

ISO 690:2010 requiere que los autores corporativos se indiquen con su
denominación completa o formal, no con abreviaturas comerciales.

| Clave          | Autor actual   | Corrección sugerida              |
|----------------|----------------|----------------------------------|
| AWS2023        | AWS            | Amazon Web Services              |
| AWS2024        | AWS            | Amazon Web Services              |
| AWS2026        | AWS            | Amazon Web Services              |
| IBM2026        | IBM            | International Business Machines  |
| Gartner2021    | Gartner        | Gartner, Inc.                    |
| Datadog2026    | Datadog        | Datadog, Inc.                    |
| Dynatrace2026  | Dynatrace      | Dynatrace LLC                    |
| NewRelic2026   | New Relic      | New Relic, Inc.                  |
| VMware2023     | VMware         | VMware, Inc.                     |

Nota: Microsoft, HashiCorp, Red Hat, Grafana Labs, FinOps Foundation,
Huawei Cloud, Google Cloud y Prometheus se consideran aceptables como
autores corporativos dado que son denominaciones reconocidas formalmente.

==============================================================

RESUMEN
==============================================================

|----------------------------------------|-------------------------------|

| Ausencia de [en línea]                 | 28 (21 @Online + 7 con URL)   |

Formato normalizado ISO 690:2010 para NOTE en entradas online:
  NOTE = {[en línea][consulta: DD mes AAAA]}

  NOTE = {[en línea][consulta: DD mes AAAA]}
